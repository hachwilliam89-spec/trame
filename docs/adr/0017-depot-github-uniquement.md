# ADR-0017 — Dépôt GitHub uniquement

- **Statut** : Accepté (2026-11-01). Remplace le miroir GitLab UHA prévu par ADR-0012.
- **Contexte** : la convention de Kim réserve GitLab UHA aux projets d'école. Trame est un projet personnel.
- **Décision** : un dépôt `trame` public sur GitHub, sans miroir. La CI reste sur GitHub Actions.
- **Conséquences** :
  - (+) Une seule source, aucune synchronisation de miroir à maintenir.
  - (−) Aucune.
