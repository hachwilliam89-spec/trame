# ADR-0001 — Sujet : planification d'équipes en entrepôt logistique

- **Statut** : Accepté (2026-11-01)
- **Contexte** : le projet doit mettre en valeur l'optimisation et la PE, montrer une complexité métier réelle, avoir un usage mobile naturel et ne pas refaire du routage (déjà traité dans RecycleDashboard, en VRPTW).
- **Décision** : planification d'équipes sous contraintes (workforce scheduling), avec les entrepôts logistiques pour cible.
- **Conséquences** :
  - (+) Le sujet s'appuie sur l'expérience terrain de Kim, le marché existe, les contraintes légales sont riches et le mobile est utile.
  - (−) Le droit du travail est complexe : il faut des règles paramétrables et une vérification juridique avant tout usage réel.
- **Alternatives écartées** :
  - optimisation de portefeuille : sujet très vu, données limitées, mobile artificiel ;
  - interventions terrain : doublon avec le VRPTW ;
  - smart charging : domaine non maîtrisé.
