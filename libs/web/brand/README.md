# Marque Trame

Tokens de palette clair/sombre séparés des composants, issus du kit logo original de Kim. Les SVG vectorisés et le favicon sont servis par `apps/web/public` ; le wordmark provient d'Outfit SemiBold (SIL OFL 1.1). Aucune police externe n'est chargée.

Ne pas déformer, recolorer ou ajouter un effet au logo. Les couleurs de surface et d'état complètent la palette d'origine pour le premier écran Guidé ; les futures maquettes pourront étendre ces tokens.
