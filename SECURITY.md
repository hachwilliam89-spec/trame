# Politique de sécurité

## Signaler une vulnérabilité

Merci de ne pas ouvrir d'issue publique pour une faille de sécurité.

Utilisez le signalement privé de GitHub : onglet **Security**, puis **Report a vulnerability**. Le signalement n'est visible que du mainteneur.

Indiquez si possible :

- la version ou le commit concerné ;
- les étapes pour reproduire ;
- l'impact estimé.

Un premier retour est donné sous 7 jours. Une fois le correctif publié, le signalement peut être rendu public avec votre accord et vos remerciements.

## Versions suivies

Seule la dernière version publiée de la branche `main` reçoit des correctifs de sécurité.

## Périmètre

La démo publique tourne avec des données fictives. Aucune donnée réelle de salarié ne doit y être saisie.
