title: Trame
description: Planification d'équipes sous contraintes, conforme au Code du travail.

Trame planifie automatiquement les équipes d'un entrepôt logistique : besoins de couverture, planning optimisé par OR-Tools CP-SAT, conforme au Code du travail, expliqué, et modifiable avec évaluation instantanée par la PE (Procédure d'Évaluation).

Cette documentation est en construction. Le cadrage et les décisions d'architecture sont dans le dépôt : `docs/cadrage.md` et `docs/adr/`.
